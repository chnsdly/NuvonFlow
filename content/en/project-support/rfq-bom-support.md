## RFQ and BOM challenges

Many project requests start as screenshots, partial line lists, mixed valve names, pipe sizes, or copied BOM rows. That is normal, but it can create hidden assumptions: one line may be missing material, another may omit end connection, and another may require an actuator or document package that is not visible.

Nuvon can help organize the request so both sides can see what is being quoted, what is assumed, and what still needs confirmation.

## What can be organized

| BOM field | Why it helps |
| --- | --- |
| Product family and function | Distinguishes isolation, check protection, throttling, dosing, relief, actuation, and accessories. |
| Size, connection, and pressure class | Reduces mismatch between quoted item and site piping. |
| Body, seat, seal, diaphragm, and gasket materials | Makes material assumptions visible for compatibility review. |
| Quantity, tags, and service notes | Helps align quotation lines with drawings, line lists, and project packages. |
| Documents and inspection needs | Prevents late-stage requests for datasheets, test records, declarations, or packing notes. |
| Commercial notes | Clarifies destination, packaging, delivery target, spare parts, and order grouping. |

## Better first quotations

Clear RFQs reduce assumptions. When assumptions are unavoidable, they should be visible in the quotation so the customer can confirm or correct them before production or shipment.

## How to send a BOM

Send the available list even if it is incomplete. Useful attachments include spreadsheets, screenshots, line lists, tag schedules, P&ID excerpts, existing product photos, installation notes, and document registers. Nuvon can return a cleaner structure with clarification questions and suggested line-item grouping.
