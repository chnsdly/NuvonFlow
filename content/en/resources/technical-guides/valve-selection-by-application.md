## Begin with the function

A valve selected for isolation, throttling, backflow prevention, sampling, dosing, pressure relief, or automated sequencing will have different priorities. Function should be named before the product family is fixed.

| Function | Common starting point |
| --- | --- |
| Compact on/off isolation for clean liquids | Ball valves |
| Larger water or low-pressure headers | Butterfly valves |
| Corrosive, dirty, or containment-focused isolation | Diaphragm valves |
| Reverse-flow prevention or pump protection | Check valves |
| Chemical dosing pressure control | Back pressure, relief, injection, and chemfeed accessories |
| Remote or automated operation | Valve and actuator package |

## Match the product family to the duty

Product family selection should follow the media, pressure, temperature, solids, leakage expectations, cycle frequency, and maintenance method. A product name by itself is rarely enough; a ball valve, diaphragm valve, or check valve can be appropriate or inappropriate depending on the actual service.

For application-led navigation, start from [industrial water treatment](/applications/industrial-water-treatment/), [industrial wastewater](/applications/industrial-wastewater/), [chemical dosing](/applications/chemical-dosing-injection/), [corrosive chemical transfer](/applications/corrosive-chemical-transfer/), or [chemical processing](/applications/chemical-processing/).

## Confirm installation constraints

Pipe standard, available space, orientation, flange compatibility, actuator clearance, valve weight, maintenance access, and drain or flush points can all affect the final selection. These items are often discovered late if the RFQ only lists product names and quantities.

## Link selection to documents

If datasheets, drawings, IOM manuals, material declarations, inspection records, or packing documents are needed, the requested document scope should be visible during quotation. Document needs can change which product configuration is practical and which supplier route is appropriate.

## Practical RFQ format

For each line item, list product function, size, connection, material direction, operating media, pressure, temperature, quantity, actuation or accessory needs, and documents required. If some data is unknown, mark it clearly so the quotation can show assumptions instead of guessing silently.
