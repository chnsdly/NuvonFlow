## 为什么文件应纳入范围

对许多国际项目来说，文件包本身就是产品范围的一部分。即使实物正确，如果数据表、图纸、材料声明、测试记录或包装文件缺失或不一致，也可能拖慢项目审批。

Nuvon 将文件视为 RFQ 阶段就应讨论的范围项，而不是货物准备发运后才补充的附属事项。

## 常见送审文件

| 文件类型 | 典型用途 |
| --- | --- |
| 技术数据表 | 确认产品系列、口径、材料、连接、压力等级和附件范围。 |
| 总图或尺寸图 | 支持布置、管道连接、安装空间和图纸评审。 |
| 安装、操作和维护手册 | 帮助项目团队核对安装、运行、维护和储存要求。 |
| 材料或符合性声明 | 用于客户要求材料可追溯或符合性声明的场景。 |
| 检验或测试记录 | 可用于压力测试、功能检查或项目质量评审。 |
| 包装和标识文件 | 帮助协调发运、标签、备件和到货检查。 |

## 文件控制说明

如果项目使用文件登记表、位号清单、版本表、文件命名规则、语言要求或审批状态流程，应在 RFQ 阶段提供这些要求。文件版本应可追踪，避免报价范围、生产确认和发运文件之间出现偏差。

## 如何申请文件

请按产品系列或行项目列出所需文件。对于项目包，建议同时提供位号、图纸参考、检验预期、目的地要求，以及文件需要在下单前、生产前、发运前还是到货后提供。
