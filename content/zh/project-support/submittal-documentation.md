## 为什么文件应进入 RFQ 范围

对许多国际项目而言，文件包本身就是供应范围的一部分。即使产品本体适用，数据表、图纸、声明、检验记录或包装文件缺失、延误或不一致，也可能阻碍审批。

应在报价前说明文件要求，使文件可用性、时间、语言、版本控制以及可能产生的商务影响与产品范围一并评审。

## 常见文件类型

| 文件 | 典型用途 |
| --- | --- |
| 技术数据表 | 记录建议产品系列、口径、材料、连接、压力等级和附件 |
| 总图或尺寸图 | 用于布置、接口、安装空间和图纸审批 |
| IOM 手册 | 支持储存、安装、运行和维护规划 |
| 材料或符合性声明 | 回应明确的客户或项目审查要求 |
| 检验或试验记录 | 记录已约定的压力、功能、外观或质量检查 |
| 包装与标识资料 | 对齐发运分组、标签、备件和收货检查 |

CAD、BIM、证书、检验记录和受控图纸并不是通用交付物。必须结合具体产品系列、配置、订单阶段和所需文件状态确认可用性。

## 需要提供的信息

说明产品系列或报价行、适用时的位号、所需文件、用途、语言、文件格式、命名规则、版本表、审批状态流程和要求日期。

如客户使用文件登记表，应直接提供登记表，而不是重新抄写到邮件中。同时说明每份文件是在订单前、生产前、发运前还是交付后需要。

## 协调方式

Nuvon 可按产品系列、行项目、位号或发运包整理申请，识别缺少的参考信息，并区分可能可提供的文件与仍需制造商确认的项目。

最终受控文件应与已确认的报价或采购订单范围一致。如果产品配置仍在变化，初步文件必须明确标识并按初步版本管理。

可把文件要求纳入 [RFQ 输入清单](/zh/resources/rfq-submittal-inputs/)，或通过[提交询价表单](/zh/request-a-quote/)发送当前文件登记表。
