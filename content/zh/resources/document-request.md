## 文件申请范围

文件申请应说明产品系列、项目名称或参考、预期文件类型、语言、版本需求和截止时间。如果文件必须匹配客户登记表，应提供登记表格式或命名规则。

当产品范围稳定时，文件最容易协调。如果材料、连接、数量、执行器或附件要求仍在变化，文件包应被视为初版或预备版本。

## 常见文件类型

| 文件 | 典型用途 |
| --- | --- |
| 数据表 | 确认基本配置、口径、材料、压力等级和附件范围。 |
| 尺寸图 | 支持布置、安装空间、管道连接和审批评审。 |
| 安装维护手册 | 提供安装、运行、储存和维护指导。 |
| 材料或符合性声明 | 用于客户要求声明文件的评审场景。 |
| 检验和测试记录 | 可用于质量评审、压力测试或功能确认。 |
| 包装和标识信息 | 帮助收货团队检查发运、标签、备件和文件。 |

## 申请最终文件前

建议确认产品范围、材料、连接、数量、文件语言、位号和版本预期已经稳定。最终受控文件应与确认后的报价或采购订单范围一致。

## Nuvon 如何协助

Nuvon 可以按产品系列、行项目、位号或发运批次整理文件申请。如果还不清楚具体文件包，请发送项目登记表或客户要求，Nuvon 可以识别哪些项目通常可提供，哪些需要进一步确认。
