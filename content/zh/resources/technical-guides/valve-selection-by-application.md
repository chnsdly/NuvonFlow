## 先明确功能

用于切断、调节、防倒流、取样、加药、泄压或自动顺序控制的阀门，选型重点并不相同。应先说明功能，再固定产品系列。

| 功能 | 常见起点 |
| --- | --- |
| 清洁液体紧凑开关切断 | 球阀 |
| 较大水管或低压主管 | 蝶阀 |
| 腐蚀性、较脏或强调隔离的工况 | 隔膜阀 |
| 防倒流或泵保护 | 止回阀 |
| 化学加药压力控制 | 背压、泄压、注入和加药附件 |
| 远程或自动操作 | 阀门与执行器组合 |

## 把产品系列匹配到工况

产品系列选择应跟随介质、压力、温度、固体、泄漏要求、启闭频率和维护方式。只有产品名称通常不够；球阀、隔膜阀或止回阀是否合适，取决于实际服务条件。

如果想按应用进入，可从[工业水处理](/zh/applications/industrial-water-treatment/)、[工业废水](/zh/applications/industrial-wastewater/)、[化学加药](/zh/applications/chemical-dosing-injection/)、[腐蚀性化学品输送](/zh/applications/corrosive-chemical-transfer/)或[化工流程](/zh/applications/chemical-processing/)开始。

## 确认安装约束

管道标准、可用空间、安装方向、法兰兼容性、执行器空间、阀门重量、维护空间和排放或冲洗点，都可能影响最终选择。如果 RFQ 只列产品名称和数量，这些问题往往会很晚才暴露。

## 把选型连接到文件

如果需要数据表、图纸、安装维护手册、材料声明、检验记录或包装文件，应在报价阶段就明确文件范围。文件要求会影响可行配置和供应路径。

## 实用 RFQ 格式

每个行项目建议列出产品功能、口径、连接、材料方向、运行介质、压力、温度、数量、执行器或附件需求，以及所需文件。若某些数据未知，应明确标记，让报价显示假设，而不是静默猜测。
